## PX4 与 Gazebo 的运行关系

运行时关系：

```text
Gazebo Classic
    负责虚拟世界、物理、模型、传感器、电机动力学

PX4 SITL
    负责飞控逻辑、状态估计、模式、控制器、MAVLink、uXRCE-DDS client

PX4 Gazebo 插件
    源码在 PX4 仓库
    编译产物在 PX4 build 目录
    运行时由 Gazebo 加载
    负责在 Gazebo 和 PX4 SITL 之间传递传感器数据和执行器指令
```

运行链路：

```text
gzserver 启动 Gazebo world
    |
    v
加载无人机模型 iris.sdf
    |
    v
通过 GAZEBO_PLUGIN_PATH 加载 PX4 编译出的 Gazebo 插件
    |
    v
插件通过 MAVLink/TCP 连接 PX4 SITL
    |
    v
PX4 接收虚拟传感器数据，输出电机/舵面控制量
    |
    v
Gazebo 根据控制量更新虚拟飞机运动
```

### README 运行命令实测修正

后续按 README 测试三终端启动时发现两个板端问题：

1. `scripts/setup_env.sh` 中 `gazebo --version` 在 RK3588 上能打印版本，但可能返回非零退出码，导致 `set -e` 下脚本提前退出。
2. PX4 自带 `sitl_multiple_run.sh` 默认启动 `gzclient`，当前板端无可用显示权限时会 abort，导致多机 SITL 脚本退出。

已处理：

- `scripts/setup_env.sh` 改为 `gazebo --version || true`。
- `/home/jie/PX4-Autopilot/Tools/simulation/gazebo-classic/sitl_multiple_run.sh` 增加 `HEADLESS=1` 分支，跳过 `gzclient` 并用 `wait` 保持进程。
- `scripts/start_px4_multi_sitl.sh` 默认导出 `HEADLESS=1`，并在调用 PX4 多机脚本时清空 `ROS_VERSION`，避免无 `gazebo_ros` 插件时出现无关加载错误。

三终端实测结果：

```text

ROS2 launch: px4_uxrce_bridge、swarm_manager、formation_controller 正常启动
```

## 可清理内容

如果只运行当前已安装环境，不再重新编译 Gazebo 或 MicroXRCEAgent，可以删除：

```bash
rm -rf /home/jie/build_gazebo_classic
rm -rf /home/jie/Micro-XRCE-DDS-Agent
sudo apt clean
```

影响：

- Gazebo 已安装到系统，删除 `/home/jie/build_gazebo_classic` 不影响运行。
- `MicroXRCEAgent` 已安装到 `/usr/local/bin/MicroXRCEAgent`，删除源码目录不影响运行。
- 删除后若要重新打包 Gazebo 或重新编译 MicroXRCEAgent，需要重新下载源码。

建议保留：

```bash
/home/jie/PX4-Autopilot
```

原因：

- PX4 SITL 没有安装成系统包。
- PX4 可执行文件、Gazebo 插件、模型、world、启动脚本仍在该目录中。
- 删除整个 PX4 目录会导致 SITL 无法直接运行。

如果只想释放 PX4 build 空间，可删除：

```bash
rm -rf /home/jie/PX4-Autopilot/build
```

影响：

- 可释放约 858M。
- 下次运行 SITL 前需要重新编译 PX4。

## 可迁移到其他同款 RK3588 的内容

Gazebo Classic 的四个 `.deb` 包可以拷贝到其他同款 RK3588 Ubuntu 22.04 arm64 板子安装：

```text
gazebo_11.10.2+dfsg-1_arm64.deb
libgazebo11_11.10.2+dfsg-1_arm64.deb
libgazebo-dev_11.10.2+dfsg-1_arm64.deb
gazebo-plugin-base_11.10.2+dfsg-1_arm64.deb
```

目标板安装示例：

```bash
sudo apt update
sudo apt install -y ./libgazebo11_11.10.2+dfsg-1_arm64.deb \
  ./gazebo_11.10.2+dfsg-1_arm64.deb \
  ./libgazebo-dev_11.10.2+dfsg-1_arm64.deb \
  ./gazebo-plugin-base_11.10.2+dfsg-1_arm64.deb
```

PX4 编译产物也可以复制，但路径敏感。更稳妥的方式是：

- Gazebo 使用已构建 `.deb` 包安装。
- PX4 在目标板上使用 `v1.14.4` 源码重新编译。
- 如果直接复制 PX4 目录，建议保持路径一致：`/home/jie/PX4-Autopilot`。
